# Contributing

Contributions should strengthen the portfolio's central promise: reproducible
analysis with explicit data, leakage, and evaluation boundaries.

## Before you start

1. Read [DATASET.md](DATASET.md) and the README's
   [design decisions](README.md#design-decisions).
2. Open an issue before adding a new dataset, target, or major model family.
3. Do not commit undocumented source data, personal information, credentials,
   trained-model binaries, notebook caches, or machine-specific paths.

## Local checks

```powershell
python -m unittest discover -s tests -v
python -m src.property_age_model --output reports/figures
ruff check .
ruff format --check .
git diff --check
```

Changes to feature selection, splitting, metrics, or source validation should
include a focused regression test. Generated figures and `metrics.json` must be
regenerated by the same code path used in CI.

## Pull requests

Explain the analytical question, the change, and the exact verification
commands. Include updated aggregate evidence when behavior changes, and keep
unrelated formatting or refactors in a separate pull request.
