# Dataset provenance

## Dwellings ML

- Upstream repository: <https://github.com/byuidatascience/data4dwellings>
- Runtime CSV: <https://raw.githubusercontent.com/byuidatascience/data4dwellings/master/data-raw/dwellings_ml/dwellings_ml.csv>
- Audited shape: 22,913 rows and 51 columns
- Target used here: `before1980`

The table contains encoded residential-property attributes used for educational data-science exercises. This project treats the upstream repository as the canonical source and downloads the CSV at runtime.

## Redistribution and scope

The upstream repository did not declare a software or dataset license when this portfolio was prepared in July 2026. For that reason, this repository does not redistribute the 3.4 MB CSV. Users should review the upstream project and obtain any permissions needed for uses beyond personal or educational analysis.

The model result is specific to this dataset and split. It is not a real-estate appraisal, building-code determination, or production decision system.
