# Support

Use the repository's issue form when a documented command, test, figure, or
published page cannot be reproduced. Include your operating system, Python
version, exact command, and a minimal error excerpt.

Questions about the upstream data source or redistribution boundary should
start with [DATASET.md](DATASET.md). Do not attach private records, credentials,
or an unpatched vulnerability to a public issue; use [SECURITY.md](SECURITY.md)
for sensitive reports.
